Sabor & Brasa

Projeto desenvolvido para praticar e aprimorar conhecimentos em desenvolvimento web, criando uma landing page para um restaurante fictício. O projeto foi construído com HTML5 e CSS3, trabalhando conceitos de estrutura semântica, organização de estilos, variáveis CSS, Flexbox, efeitos de interação e adaptação visual. A página apresenta seções de início, cardápio, sobre o restaurante e contato, com foco em uma interface moderna e agradável. O projeto também faz parte da minha prática de desenvolvimento de interfaces para web e será aprimorado com JavaScript e responsividade.
